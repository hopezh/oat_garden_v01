03 / DISTILLED STYLE DNA

The family essence

The two token sets converge so strongly that the shared core is unambiguous — same accent, same typeface, same zero-radius black canvas:

// style-dna.tokens.json (DTCG-style, abbreviated)
{
  "color": {
    "canvas":    "#000000",   // pure black — both sites
    "surface":   "#1c1c1c",
    "text":      "#ffffff",
    "text-muted":"#717171",
    "accent":    "#c0fe04",   // acid green — THE shared signature
    "alert":     "#f24723"    // orange-red — Marathon signal
  },
  "font":  { "mono": "PP Fraktion Mono", "display": "Shapiro" },
  "shape": { "radius": "0px", "border": "1px solid {accent}" },
  "space": { "base": "4px" },
  "motion":{ "duration": "150ms", "easing": "cubic-bezier(.4,0,.2,1)" }
}
Shared core — keep universal

The 5 principles

  • Black canvas, two signal accents (green + red), used sparingly.
  • Monospace is the voice; Shapiro reserved for poster scale.
  • Sharp, not soft — radius 0; structure from 1px green hairlines.
  • Uppercase codenames; tight display leading.
  • Mission-briefing / HUD tone — // separators, surface-data framing.
Per-site — deliberately excluded

Idiosyncrasies

  • Marathon — huge Shapiro super-display, the orange-red accent, cinematic photography, asymmetric editorial hero.
  • Tau Ceti — near-total mono uniformity, dense map/HUD chrome, green outline grids, lowercase command prefixes (explorer:).

05 / FINDINGS

Working with Claude on style distillation

  1. The two-layer split held. Tokens came out mechanically; the higher-order layer (voice, HUD framing, layout intent) needed Claude's interpretation — where the model earns its keep.
  2. You often don't need a dedicated extractor. For Marathon (Next.js), curl + the live CSS variables gave a complete token set; MCP extractors are convenience, not requirement.
  3. The real bottleneck is access, not parsing. Bot-protected sites defeat simple fetches; driving a real browser and reading getComputedStyle is the reliable fallback — arguably the default for the token step.
  4. A coherent family makes distillation trivial; the value is naming the deltas. When sites already share tokens, synthesis is confirmation — the useful output is the explicit shared-vs-per-site split.
  5. Grounding beats slop, measurably — see the A/B.
06 / WORKFLOW

Recommended repeatable loop

  1. Token step — drive a real browser; one getComputedStyle sweep → tally colors, fonts, sizes, radii, borders. (Falls back to curl + CSS vars for open static sites.)
  2. Higher-order step — Claude reads the live page for voice, layout intent, motion, casing.
  3. Distill — merge tallies → style-dna.tokens.json + a short DESIGN.md, with an explicit shared-vs-per-site split.
  4. Apply — feed the DNA + the Frontend Design skill; generate the target.
  5. Verify — A/B against an ungrounded control on the rubric.
