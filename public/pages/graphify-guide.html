Knowledge graph for your codebase

The Complete Graphify Guide

Map an entire codebase — code, docs, PDFs, images — into a queryable knowledge graph of god nodes, named communities, and cross-file relationships. This guide covers every step for three setups: terminal-only (offline), Claude Code, and Antigravity.

📦 Package graphifyy ⌨️ CLI graphify 🐍 Python 3.10+ ⚖️ MIT

⚡ TL;DR

  • Install once: uv tool install graphifyy — the package is graphifyy (double-y), the command is graphify.2
  • Code is always local & free (tree-sitter AST). Only docs/PDFs/images need an LLM — your assistant in Claude Code/Antigravity, or local Ollama offline.3
  • Build: graphify extract . in a terminal, or type /graphify . inside Claude Code / Antigravity (uses your plan, no API key).1
  • Query with query / path / explain; keep current with graphify hook install (free, post-commit) and graphify update ..1

SECTION 1

Setup guide — reusable for any project

This section is once per machine. Everything after it is once per project.

1.1 Install uv, the recommended Python tool manager

uv installs graphify as an isolated global tool so it never collides with a project's virtualenv. You can substitute pipx or pip (see 1.3).7

PowerShell
winget install astral-sh.uv
# or, without winget:
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
uv --version
bash
brew install uv
# or:
curl -LsSf https://astral.sh/uv/install.sh | sh
uv --version
bash
curl -LsSf https://astral.sh/uv/install.sh | sh
uv --version

1.2 Install graphify globally

Same command on every OS. Remember the name twist: the package is graphifyy (double-y); the command is graphify.1

bash
uv tool install graphifyy
graphify --version

1.3 Alternatives & PATH notes

bash
pipx install graphifyy   # isolated, like uv tool
pip  install graphifyy   # into the active environment
Windows: if graphify isn't found after pip, add %APPDATA%\Python\Python3xx\Scripts to PATH, or use pipx.  macOS: if pip fails with externally-managed-environment, use uv tool install or pipx instead.3

1.4 Per-scenario setup

Pick your way of working. The terminal commands later are identical; only the LLM provider differs.

Terminal only (offline). Nothing beyond steps 1.1–1.2. Optionally install Ollama for local semantic extraction of docs/PDFs/images, then pull a model.
bash (optional)
# optional, only for offline doc/PDF/image extraction
ollama pull llama3.1
Claude Code. Have Claude Code installed and signed in (subscription) — or set ANTHROPIC_API_KEY for headless terminal use.
Antigravity. Install Google's agy CLI, then sign in with a Google AI account — or set GEMINI_API_KEY for headless terminal use.6
bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
agy --version
PowerShell
irm https://antigravity.google/cli/install.ps1 | iex
agy --version

SECTION 2

Register the skill with your AI assistant

Teach the assistant to reach for the graph first instead of reading raw files. This writes a skill/instruction file and registers a /graphify command.5

Nothing to register. There's no assistant in the offline scenario — skip this section and drive graphify directly from the terminal in every later step.
Claude Code. Choose global (all projects) or --project (this repo only). On Windows use the --platform windows target.
bash
cd path/to/your/project

# Global (all projects on this machine):
graphify install
# Windows:
graphify install --platform windows

# Project-scoped (writes into this repo only):
graphify install --project

What it writes3

  • ~/.claude/skills/graphify/SKILL.md (or .claude/skills/graphify/ with --project) — the skill definition.
  • A registration line in CLAUDE.md so Claude knows the /graphify trigger exists.
  • A PreToolUse hook in settings.json so the graph is consulted automatically.

After this, type /graphify inside Claude Code to use it.

Antigravity. Uses its own subcommand form. Add --project for repo scope.
bash
cd path/to/your/project

graphify antigravity install
# project-scoped:
graphify antigravity install --project

What it writes — Antigravity's always-on layer6

  • .agents/rules/graphify.md — always-on rule telling the agent to consult the graph.
  • .agents/workflows/graphify.md — registers /graphify as a slash workflow.
Known gotcha (Issue #453): older releases created .agent/ (singular) instead of .agents/ (plural), which Antigravity ignores. If /graphify doesn't appear, check and rename the folder. Fixed recently — upgrade with uv tool upgrade graphifyy.4

Other assistants (reference)

graphify supports ~20 targets. Note the two syntaxes: most use --platform X; Cursor / VS Code / Kiro / Devin / Antigravity use graphify <target> install.1

SECTION 3

Build the knowledge graph

Produces graphify-out/ with graph.html (interactive visual), GRAPH_REPORT.md, and graph.json.3

3.1 Optional — scope what gets scanned

Create a .graphifyignore (same syntax as .gitignore) to skip noise. For a code-only graph (ideal offline), exclude prose:

.graphifyignore
*.md
*.txt
*.rst
*.yaml
*.yml
*.toml
*.html

3.2 Build it — by scenario

Offline. Code is parsed locally with tree-sitter — no API key, nothing leaves your machine. Add a local Ollama backend to also extract docs/PDFs/images offline.
bash
cd path/to/your/project
graphify extract .

# also extract docs/PDFs/images, fully offline via Ollama:
graphify extract . --backend ollama --max-workers 16
Claude Code. Type the slash command — semantic extraction runs on your Claude plan, no separate API key needed.
in Claude Code
/graphify .
bash — headless w/ API key
ANTHROPIC_API_KEY=sk-ant-... graphify extract .
Antigravity. Type the workflow — extraction runs on your Google AI plan.
in Antigravity
/graphify .
bash — headless w/ API key
GEMINI_API_KEY=... graphify extract . --backend gemini
Offline vs not: code (.py .ts .js .go .rs .java .c .cpp .rb .cs .kt .scala .php …) is AST-parsed locally and free in every scenario. Only docs/PDFs/images need an LLM. Every edge is tagged EXTRACTED, INFERRED, or AMBIGUOUS so you always know what was found vs guessed.3

SECTION 3 · REPORT

Generate the report & named communities

Community detection groups densely-connected nodes into clusters; the report surfaces god nodes (highest-degree hubs). extract runs this once — re-run it standalone to re-cluster without re-extracting.3

Communities cluster related nodes; god nodes are the highest-degree hubs everything connects through.
Offline. Cluster without LLM labels — communities get structural names. Tune with --resolution / --exclude-hubs.
bash
graphify cluster-only . --no-label

# tuning
graphify cluster-only . --resolution 1.5    # higher = more, smaller communities
graphify cluster-only . --exclude-hubs 99   # ignore top-degree hubs while clustering
Claude Code. Let Claude name the communities in plain English.
in Claude Code
/graphify . --cluster-only
bash — headless w/ API key
ANTHROPIC_API_KEY=sk-ant-... graphify cluster-only .
Antigravity. Gemini names the communities.
in Antigravity
/graphify . --cluster-only
bash — headless w/ API key
GEMINI_API_KEY=... graphify cluster-only .

Open the report & visual (all scenarios)

The report lives at graphify-out/GRAPH_REPORT.md; the interactive visual is graphify-out/graph.html — open it in any browser, no server needed.

bash
start graphify-out\graph.html    # Windows
open  graphify-out/graph.html    # macOS
xdg-open graphify-out/graph.html # Linux

SECTION 4

Query the knowledge graph

Three query modes — broad questions, relationship paths, or focused concept explainers.1

ModeUse it for
query "…"Broad questions — runs a BFS subgraph query and synthesizes an answer.
path "A" "B"The shortest relationship path between two nodes.
explain "X"A focused deep-dive on one concept.
Offline. Natural-language synthesis needs an LLM, so fully-offline querying means either browsing the outputs directly, or pointing at a local Ollama model.
  • Browse directly — open graphify-out/graph.html (search + filter by community) and read GRAPH_REPORT.md.
  • Local model for synthesized answers:
bash
graphify query "what are the main components?" --backend ollama
graphify path    "ModuleA" "ModuleB"
graphify explain "SomeClass"
Claude Code. Answers synthesized on your Claude plan.
in Claude Code
/graphify query "what connects auth to the database?"
/graphify path "UserService" "DatabasePool"
/graphify explain "RateLimiter"
bash — headless w/ API key
ANTHROPIC_API_KEY=sk-ant-... graphify query "what are the main components?"
Antigravity. Answers synthesized on your Google AI plan.
in Antigravity
/graphify query "what connects auth to the database?"
/graphify path "UserService" "DatabasePool"
/graphify explain "RateLimiter"
bash — headless w/ API key
GEMINI_API_KEY=... graphify query "what are the main components?" --backend gemini

SECTION 5

Auto-rebuild on git commit

Installs a post-commit hook that rebuilds the graph after every commit. It runs AST extraction only — no API cost, so it behaves identically in all three scenarios.1

bash
graphify hook install     # add the post-commit hook
graphify hook status      # check whether it's installed
graphify hook uninstall   # remove it
Because the hook is code-only, your graph's structure stays current automatically and for free. Re-run LLM community naming (Section 3 · Report) only when you want fresh labels.

SECTION 6

Keeping the graph up to date

After editing code, do an incremental update — it reprocesses only changed files (tracked via a SHA256 cache), so it's fast and, for code, free.3

6.1 Update the graph data

bash
graphify update .               # incremental AST update (changed files only)
graphify update . --no-cluster  # skip re-clustering (faster)
graphify update . --force       # overwrite even if the new graph has fewer nodes

Inside an assistant (Scenario B/C) you can instead type the slash forms:

in assistant
/graphify . --update    # re-extract changed files
/graphify . --watch     # auto-sync while you work

6.2 Re-name communities after big changes

bash
graphify cluster-only . --no-label   # A: structural only, offline
graphify cluster-only .              # B/C: LLM-named (needs assistant or key)

6.3 Upgrade the tool

bash
uv tool upgrade graphifyy   # or: pipx upgrade graphifyy / pip install --upgrade graphifyy
update vs upgrade — don't confuse them. graphify update refreshes the graph data. Upgrading the program is done with your package manager; there is no graphify upgrade subcommand.3
