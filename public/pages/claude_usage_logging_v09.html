Claude Code · session usage logging

Logging the /status panel, automatically.

A SessionEnd hook rebuilds the Usage panel from each session's transcript and appends it to a local log — no copy-paste, with a manual /log-status snapshot and weekly / monthly rollups alongside.

TL;DR

  • The Usage panel's numbers aren't handed to hooks — the hook gets the transcript path and the figures are rebuilt from that JSONL.[1]
  • Cost, wall time and per-model tokens come back faithfully; API duration is a close timestamp estimate; the exact API counter is the only thing not recoverable.[2]
  • Three files: a hook logger, a weekly/monthly rollup, and a manual /log-status command — all downloadable below.
  • Cost is computed from a local rate table (Opus $5/$25, Sonnet $3/$15, Haiku $1/$5).[3]
  • Tag each session by account — work vs personal — from your launch wrapper, and the rollup breaks usage down per account.

01 Overview

Claude Code's /status → Usage panel reports a session's total cost, API and wall duration, code changes, and per-model token usage. The goal: save those figures automatically every time a session ends, instead of reading them off the screen.

The mechanism is the SessionEnd hook, which fires when a session terminates.[1] It runs a script that reconstructs the panel from the session transcript and appends a record to ~/.claude/usage/sessions.jsonl and a flat sessions.csv.

The catch

The hook's payload carries only session_id, transcript_path, cwd, and reason — not the panel's computed numbers.[1] So you don't capture the panel; you rebuild it from the transcript JSONL, the same source /cost and ccusage read.[5]

02 What gets captured

Each Usage-panel field maps to a field in the log record, with a known fidelity:

Panel fieldLog fieldFidelity
Total costcost_usd_estrate table
Total duration (API)api_duration_s_estestimated
Total duration (wall)wall_duration_sexact
Total code changeslines_added / lines_removedbest-effort
Usage by modelby_modelexact tokens

API-duration estimate

Claude Code logs a real per-turn duration in the transcript (a turn_duration system entry), so the script sums those when present and only falls back to a timestamp-gap estimate otherwise — landing within a couple of seconds of the panel. Usage is also de-duplicated per response id, because a single API response can be split across several transcript lines (thinking + tool_use), each carrying the full usage; counting them once avoids doubling that turn's tokens.

Cost breakdown

A worked example validates the rate table: an Opus 4.8 turn billing 3.1k input, 1.5k output, 127.6k cache read and 9.5k cache write reconciles to $0.176 — matching the real panel reading. Cache write bills at 1.25× input, cache read at 0.1×.[4]

Per-account tagging

To separate subscription sessions from company-API-key sessions, stamp the account at launch — the transcript carries no reliable auth field. The two highlighted lines slot into the Claude Context Switcher functions you already use, keeping the switcher's scoped, per-call style (no global export); the hook inherits the variable and records an account field.

# ── Claude Code: work (API key) vs personal (Pro subscription) ──

claude-work() {
  local api_key
  api_key=$(security find-generic-password \
              -a "$USER" -s "anthropic-api-key" -w 2>/dev/null)

  if [[ -z "$api_key" ]]; then
    echo "Error: API key not found in Keychain." >&2
    echo 'Run: security add-generic-password -a "$USER" -s "anthropic-api-key" -w' >&2
    return 1
  fi

  CLAUDE_USAGE_ACCOUNT="work" ANTHROPIC_API_KEY="$api_key" claude "$@"
}

claude-personal() {
  local _saved="$ANTHROPIC_API_KEY"
  unset ANTHROPIC_API_KEY

  CLAUDE_USAGE_ACCOUNT="personal" claude "$@"
  local _rc=$?

  [[ -n "$_saved" ]] && export ANTHROPIC_API_KEY="$_saved"
  return $_rc
}
# ── Claude Code: work (company API key) vs personal (Pro subscription) ──
$Global:ClaudeKeyFile = "$HOME\.config\claude\anthropic-key.xml"

function claude-work {
    if (-not (Test-Path $Global:ClaudeKeyFile)) {
        Write-Error "Encrypted key not found at $Global:ClaudeKeyFile"
        return
    }
    $sec = Import-Clixml $Global:ClaudeKeyFile
    $env:ANTHROPIC_API_KEY =
        [System.Net.NetworkCredential]::new("", $sec).Password
    $env:CLAUDE_USAGE_ACCOUNT = "work"
    try {
        claude @args
    } finally {
        Remove-Item Env:\ANTHROPIC_API_KEY    -ErrorAction SilentlyContinue
        Remove-Item Env:\CLAUDE_USAGE_ACCOUNT -ErrorAction SilentlyContinue
    }
}

function claude-personal {
    $saved = $env:ANTHROPIC_API_KEY
    Remove-Item Env:\ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
    $env:CLAUDE_USAGE_ACCOUNT = "personal"
    try {
        claude @args
    } finally {
        Remove-Item Env:\CLAUDE_USAGE_ACCOUNT -ErrorAction SilentlyContinue
        if ($saved) { $env:ANTHROPIC_API_KEY = $saved }
    }
}

Without the variable, the script falls back to sniffing for an API-key env var (api_key vs subscription) — only accurate if the key is exported into the environment, so the explicit label is the dependable path. The report then prints a By account table, and --account work scopes the weekly / monthly views.

Notional cost for subscription sessions. Plan sessions aren't billed per token, so their cost_usd_est is the equivalent API value — what those tokens would have cost — not money owed. Token counts and durations are real either way.

03 Components

SessionEnd hook · the engine log_usage.py

Parses the transcript and appends one record per session to sessions.jsonl and sessions.csv. Runs from the hook (--hook), an explicit --transcript, or auto-discovery.

Rollup · the read-out usage_report.py

Reads the log and prints weekly and monthly tables — sessions, cost, API/wall hours, tokens, lines changed. Dedupes by session so manual snapshots never double-count.

Slash command · manual snapshot log-status.md

Drop in ~/.claude/commands/. Typing /log-status mid-session snapshots usage-so-far without quitting.

04 Setup

  1. Place the files. log_usage.py and usage_report.py into ~/.claude/hooks/; log-status.md into ~/.claude/commands/.
  2. Register the hook in ~/.claude/settings.json (every project; effective next session). 
    {
  "hooks": {
    "SessionEnd": [
      { "hooks": [ { "type": "command",
        "command": "python3 ~/.claude/hooks/log_usage.py --hook",
        "timeout": 30 } ] }
    ]
  }
}
    {
  "hooks": {
    "SessionEnd": [
      { "hooks": [ { "type": "command", "command": "python",
        "args": ["C:\\Users\\UserName\\.claude\\hooks\\log_usage.py", "--hook"],
        "timeout": 30 } ] }
    ]
  }
}
  3. Quit a session — a record lands in sessions.jsonl and sessions.csv.
  4. Review anytime. 
    python3 ~/.claude/hooks/usage_report.py            # last 8 weeks + 6 months
python3 ~/.claude/hooks/usage_report.py --months 12
python3 ~/.claude/hooks/usage_report.py --all

05 Pricing

ModelInput / 1MOutput / 1MCache writeCache read
Opus 4.8$5$25$6.25 (1.25×)$0.50 (0.1×)

Cost is computed locally from this table in log_usage.py, set to current standard rates.[3][4] It does not model Fast Mode (Opus $10/$50) or the US-only-inference 1.1× surcharge, so enabling either makes the logged cost read low until the table is updated. Models match by substring, so point releases keep working without edits.
