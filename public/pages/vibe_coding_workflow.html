The Problem

Why Casual AI Coding Fails

AI makes code generation look easy. Without structure, complex projects quickly become unmaintainable.

"Fix one thing and something else breaks. Implement one feature and another stops working. After spending millions of tokens the code becomes a garbage dump."

— The core frustration with unstructured vibe coding, as described in the video

⚠️
Context window overload
▼
When everything lives in one agent's context, the AI auto-compresses prior conversation. This drops critical implementation details — precise function signatures become vague descriptions, edge cases disappear — leading to subtle bugs and module inconsistencies.
🌀
Ambiguous requirements → hallucinations
▼
The root cause: you don't know exactly what you want. When requirements are fuzzy, AI fills gaps with guesses. People then iterate reactively — accumulating technical debt instead of clarifying upfront.
🏗️
No module boundaries = tangled code
▼
Generating all code in one shot produces a monolith where everything is coupled. When AI touches one area it breaks another. Independent modules are the only way to ensure AI can safely add features without regression.

The Prompt Framework

Structure Every AI Message in 4 Parts

Every prompt should have all four parts. The final part — Steps — is where the magic happens.

Part 1

Goal (目標)

State the single, clear objective. Not "build an app" but "build an FC emulator that runs Super Mario Bros."

Part 2

Input (輸入)

Describe what you're providing: specific files, existing code structure, known constraints. Anchors AI to your actual project.

Part 3

Output (輸出)

Specify exactly which file(s) to generate, in what format, and where. "Generate docs/proposal.md" beats "write a requirements doc."

Part 4 — Key

Steps (步驟)

Don't describe what to build — describe how to approach it. Killer technique: instruct AI to ask you questions instead of guessing.

## GOAL Develop an FC emulator in Python that runs Super Mario Bros. Help me generate a requirements document. ## INPUT - UV-managed Python workspace (empty) - roms/super_mario.nes for testing ## OUTPUT Generate docs/proposal.md ## STEPS I have zero FC emulator knowledge. Use questions to help me clarify requirements. Do NOT guess my intent — ask about anything unclear. → AI interviews YOU → surfaces unknowns → fewer bugs later

Single Agent

  • Context grows without bound
  • Auto-compression loses details
  • Serial execution only
  • Regressions between modules

Multi-Agent

  • Each agent has short, focused context
  • No compression — all details preserved
  • Modules developed in parallel
  • Failures are isolated & restartable
Code Quality

Quality Gates at Every Level

Tests and static analysis are load-bearing architecture — they enable continued AI development without regression.

🔍

mypy

Static type checker. Catches type mismatches before runtime.

⚡

ruff

Fast linter and formatter. Enforces consistent style automatically.

🧪

pytest

Unit tests required for every generated line. Tasks don't close until tests pass.

🛡️

Regression Safety

Tests prevent AI breaking existing features when adding new ones.

Key Principles

The Mental Model

Distilled rules from the workflow that apply beyond this specific project.

🗣️

Make AI ask you questions

Explicitly instruct AI not to guess. Any ambiguity must be surfaced as a question before generating anything.

📁

Files beat chat history

Every decision goes into a file. New chat sessions read the file. Chat history is disposable; files are durable.

🔬

Modules must be independent

Design every module to be testable in isolation. This is the single biggest lever for AI code quality.

🧪

Tests are non-negotiable

Require tests for every generated line. No exceptions. Tests are the only mechanism that makes AI projects maintainable.

🤖

Humans command only the master

Once coding begins, interact with one orchestrator only. Sub-agents execute autonomously. Leverage is in the upfront prompts.

📐

Let AI build the prompts too

The complex multi-agent prompt.md is itself AI-generated. Meta-prompting reduces cognitive load and produces consistent results.
