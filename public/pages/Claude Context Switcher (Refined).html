3

Save the API key securely

Keychain DPAPI

macOS ships with the security CLI that reads and writes the system Keychain. Your key is encrypted at rest and protected by your login password — no third-party vault required.

3a — Store the key (run once)
zsh 
security add-generic-password \
  -a "$USER" \
  -s "anthropic-api-key" \
  -w
# Input is hidden — type or paste, then press Enter
3b — Verify the key was saved
zsh 
security find-generic-password \
  -a "$USER" \
  -s "anthropic-api-key" \
  -w
# Should print your key
3c — Update the key later
zsh 
security add-generic-password \
  -a "$USER" \
  -s "anthropic-api-key" \
  -U \    # -U = update if already exists
  -w
3d — Delete the key (if needed)
zsh 
security delete-generic-password \
  -a "$USER" \
  -s "anthropic-api-key"

PowerShell's Export-Clixml encrypts a SecureString using Windows DPAPI, tied to your login account. The key is unreadable to other users and is never stored in plain text.

3a — Store the key (run once)
PowerShell 
New-Item -ItemType Directory -Force -Path "$HOME\.config\claude" | Out-Null

$key = Read-Host "Paste your API key" -AsSecureString
$key | Export-Clixml "$HOME\.config\claude\anthropic-key.xml"
3b — Verify the key was saved
PowerShell 
$sec = Import-Clixml "$HOME\.config\claude\anthropic-key.xml"
[System.Net.NetworkCredential]::new("", $sec).Password
# Should print your key
3c — Update the key later
PowerShell 
$key = Read-Host "Paste new API key" -AsSecureString
$key | Export-Clixml "$HOME\.config\claude\anthropic-key.xml"
# Overwrites the existing file
3d — Delete the key (if needed)
PowerShell 
Remove-Item "$HOME\.config\claude\anthropic-key.xml"
4

Add two shell functions to your profile

~/.zshrc $PROFILE

Open ~/.zshrc in any editor and append the block below.

~/.zshrc 
# ── Claude Code: work (API key) vs personal (Pro subscription) ──

claude-work() {
  local api_key
  api_key=$(security find-generic-password \
              -a "$USER" -s "anthropic-api-key" -w 2>/dev/null)

  if [[ -z "$api_key" ]]; then
    echo "Error: API key not found in Keychain." >&2
    echo 'Run: security add-generic-password -a "$USER" -s "anthropic-api-key" -w' >&2
    return 1
  fi

  ANTHROPIC_API_KEY="$api_key" claude "$@"
}

claude-personal() {
  local _saved="$ANTHROPIC_API_KEY"
  unset ANTHROPIC_API_KEY

  claude "$@"
  local _rc=$?

  [[ -n "$_saved" ]] && export ANTHROPIC_API_KEY="$_saved"
  return $_rc
}

Open your PowerShell profile (notepad $PROFILE) and append the block below.

$PROFILE 
# ── Claude Code: work (company API key) vs personal (Pro subscription) ──
$Global:ClaudeKeyFile = "$HOME\.config\claude\anthropic-key.xml"

function claude-work {
    if (-not (Test-Path $Global:ClaudeKeyFile)) {
        Write-Error "Encrypted key not found at $Global:ClaudeKeyFile"
        return
    }
    $sec = Import-Clixml $Global:ClaudeKeyFile
    $env:ANTHROPIC_API_KEY =
        [System.Net.NetworkCredential]::new("", $sec).Password
    try {
        claude @args
    } finally {
        Remove-Item Env:\ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
    }
}

function claude-personal {
    $saved = $env:ANTHROPIC_API_KEY
    Remove-Item Env:\ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
    try {
        claude @args
    } finally {
        if ($saved) { $env:ANTHROPIC_API_KEY = $saved }
    }
}
💡
How it works: claude-work fetches the key from Keychain and passes it as a scoped env var — never exported globally, so other terminals are unaffected. claude-personal temporarily unsets any key so Claude falls back to your logged-in subscription, then restores it on exit. claude-work decrypts the key and injects ANTHROPIC_API_KEY only for the call duration — a finally block guarantees cleanup even if Claude errors. claude-personal removes the variable so Claude falls back to your logged-in subscription, then restores it on exit.
