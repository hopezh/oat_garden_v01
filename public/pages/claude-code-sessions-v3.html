TL;DR — to start a fresh context window inside a running session, just type /clear.

Conversation summary

Starting a new chat with a fresh context window in Claude Code.

In Claude Desktop, every session gets its own context window. This is how to get the same clean slate when running Claude from the terminal — plus the commands for resuming, branching, and trimming context.

01

The short answer

The equivalent of "starting a new chat" in the Claude Code CLI is the /clear command. While you're inside a running claude session, type it to wipe the conversation history and get a blank context window — without leaving the terminal session.

→ do this
/clear start fresh

It's like opening a new document in a word processor without closing the app: the terminal session keeps running, but the conversation history is erased and the context window is empty.

02

How /clear actually works

A nuance worth knowing if you like to verify things empirically: under the hood, /clear doesn't literally zero out the current session. The previous conversation is saved and resumable.

It mints a new conversation ID, so the old transcript is preserved on disk and you can return to it later. Functionally, though, your context window is fresh — which is the goal.

Command reference

Depending on what you actually want, here are the relevant options — inside-session commands and shell flags.

Wipe history, blank context, keep the session alive. The default "new chat".

04

Clear vs. restart vs. compact

All three change what's in the window, but they behave differently. Restart re-reads your CLAUDE.md; /clear keeps the process alive without reinitializing — so it's faster and the recommended default unless you've changed project config.

ActionClears contextKeeps sessionRe-reads CLAUDE.md
/clearYesYesNo
/compactSummarizedYesNo
restart claudeYesNoYes
05

Recommended workflow

The habit most people land on, mapped to a multi-tool day:

/clear
Between unrelated tasks — e.g. switching from a Three.js HUD task to a PyTorch debugging task.
/compact
When a single long task starts eating context but you want to keep the thread going.
restart
When switching projects or after major CLAUDE.md changes, so config is re-read.
--continue / -r
When you want to pick back up where a previous session left off.
