Graphify Setup Guide
Knowledge Graph for Your Codebase

Set up Graphify
on any project

Map your entire codebase into a queryable knowledge graph — god nodes, communities, cross-file relationships — all from a single command.

📦 Package: graphifyy 🐍 Python 3.10+ 🔗 github.com/safishamsi/graphify
📋

Reusable setup guide — any project

0
Prerequisites — once per machine
Install uv (the recommended Python package manager) and verify it's on your PATH.
PowerShell 
winget install astral-sh.uv
uv --version
bash 
brew install python@3.12 uv
uv --version
bash 
curl -LsSf https://astral.sh/uv/install.sh | sh
uv --version
1
Install graphify globally
The PyPI package is graphifyy (double-y). The CLI command is still graphify.
bash 
uv tool install graphifyy
graphify --version
2
Navigate to your project and register the skill
This writes a SKILL.md and updates CLAUDE.md so your AI assistant uses the graph first.
bash 
cd path/to/your/project
graphify install --project
3
Build the knowledge graph
Choose the approach that matches your setup.
Create a .graphifyignore to skip doc files, then extract. No API key required — fully offline via tree-sitter AST.
.graphifyignore 
*.md
*.yaml
*.yml
*.txt
*.rst
*.html
*.toml
bash 
graphify extract .
bash 
ANTHROPIC_API_KEY=sk-ant-... graphify extract .
bash 
OPENAI_API_KEY=sk-... graphify extract .
bash 
GEMINI_API_KEY=... graphify extract .
4
Generate the report & name communities
Runs community detection and writes graphify-out/GRAPH_REPORT.md.
bash 
graphify cluster-only . --no-label
bash 
ANTHROPIC_API_KEY=sk-ant-... graphify cluster-only .
5
Query the graph
Three query modes — broad questions, relationship paths, or focused concept explainers.
bash 
graphify query "what are the main components?"
graphify path  "ModuleA" "ModuleB"
graphify explain "SomeClass"
6
Auto-rebuild on git commit (optional)
Installs a post-commit hook. AST extraction only — no API cost.
bash 
graphify hook install
7
Open the interactive visual (optional)
The HTML file is fully self-contained — open it in any browser, no server needed.
bash 
start graphify-out/graph.html   # Windows
open  graphify-out/graph.html   # macOS / Linux
🔄

Keeping the graph up to date

Command When to use it
graphify update . After editing code — incremental AST update, no API cost
graphify update . --force After a large refactor that deletes many files
graphify cluster-only . --no-label Re-run community detection without re-extracting
graphify hook install Auto-update after every git commit
uv tool upgrade graphifyy Upgrade graphify to the latest version
⚡

Quick reference — all key commands

Command What it does
graphify extract . Full extraction (code + docs if API key set)
graphify cluster-only . Re-cluster without re-extracting
graphify query "…" BFS subgraph query — best for broad questions
graphify path "A" "B" Shortest relationship path between two nodes
graphify explain "X" Deep-dive on a single concept
graphify install --project Register skill + update CLAUDE.md for this project
graphify hook install Post-commit auto-rebuild hook
graphify export callflow-html Mermaid call-flow architecture HTML
graphify uninstall --purge Remove graphify from all platforms + delete graphify-out/
